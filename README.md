# Moddue

Minimal React + TypeScript application using Vite. The initial page is intentionally blank.

## Development

Use Node.js 24 LTS and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. Start adding page content in `src/App.tsx`.

## Validation

```sh
npm run typecheck
npm run build
```

React Aria Components is installed for future accessible UI. Product features and automated test tooling have not been added yet.
